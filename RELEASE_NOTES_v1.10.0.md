# FlowMLLab v1.10.0

This release adds Weeks 17–22 to the established CFD/SciML course and publishes
the corrections following independent review. The course now has 50 notebooks
and 33 lecture PDFs, with all modules linked from the main course table.

- Six CPU laboratories cover Q/K/V attention, next-character language modeling,
  tokenization and sensor design, missing-observation reconstruction, autonomous
  prediction and transfer/information-budget audits.
- Each new week includes four coding exercises, an executed student notebook,
  separate instructor solutions, an editable lecture and a five-page PDF.
- The numerical comparisons include classical and neural baselines, saved
  representation diagnostics, fully counted target labels, matched-update
  controls and a paired three-seed sensor-augmentation ablation. Checkpoint
  verification reports strict and declared scientific criteria separately.
- Six homepage/weekly-page previews now use native-grid CFD velocity/vorticity
  contours, sensor markers and absolute spatial error. Shared color scales,
  fixed snapshots and a provenance manifest support direct interpretation.
- Python distribution, runtime, citation and Zenodo metadata consistently report
  version 1.10.0. The portable Weeks 17–22 package includes the new landing pages
  and contour assets, together with its data, evidence and editable sources.

Existing prediction/checkpoint archives and original instructional figures are
preserved. The source release and portable package retain their checksums and
reproduction instructions; older large CFD inputs remain available at their
original, explicitly pinned releases.

Validation covers the package/release gates, scientific evidence, 24 coding
exercises and semantic mutation checks, independent checkpoint reconstruction,
the paired augmentation evidence, and all 12 new notebooks in fresh kernels.
See `docs/TRANSFORMER_SECOND_REVIEW_RESPONSE.md` and the GitHub Actions runs for
the released revision. The contour update separately checked 20 numerical
reference/prediction panels, displayed snapshot norms and 383 local links.

Interactive Colab sessions and a representative student workload/grading pilot
remain open classroom-acceptance checks. Previously inspected coarse LBM wakes
are retained evaluation cases, not new blind tests or grid-independence
evidence. The character language model and continuous-state CFD decoder remain
separate experiments; matched optimizer-update ceilings do not establish equal
FLOPs or source information. The earlier NASA reproduction limitations remain
unchanged. This is an open teaching/software release, not institutional course
approval or a claim of new scientific superiority.
