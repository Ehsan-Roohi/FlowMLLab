# FlowMLLab v1.0.1

FlowMLLab v1.0.1 is a corrective archival release of the validated
CFD-to-scientific-machine-learning framework.

## Changes from v1.0.0

- replaces an incomplete external archive with a byte-verified GitHub tag archive;
- updates the package, citation, README, and Zenodo metadata to version 1.0.1;
- retains the same numerical solvers, data, notebooks, lectures, tests, and scientific results;
- records MIT licensing and the version DOI `10.5281/zenodo.22074127`; and
- preserves the standalone repository boundary, so no separate JFM or R13/R26 materials are included.

The release archive must pass `unzip -t` before publication. Its repository
quality gates remain `flowmllab smoke`, `flowmllab qa`, and the Python
3.10--3.12 GitHub Actions matrix.

The v1.0.1 release supersedes v1.0.0 for citation and SoftwareX evaluation.
