# FlowMLLab v1.0.0

FlowMLLab v1.0.0 is the first software-centered release of the reproducible
CFD-to-scientific-machine-learning framework.

## Release scope

- installable `flowmllab` Python package defined by `pyproject.toml`;
- `flowmllab smoke`, `flowmllab qa`, and `flowmllab figures` command-line entry points;
- fixed cavity dataset with SHA-256 verification and boundary-condition checks;
- direct Ghia velocity, Botella--Peyret pressure, and Mohammadzadeh DSMC validation;
- coordinate-MLP and POD-DeepONet blind-field evidence;
- neural-DSMC higher-moment and Fokker--Planck closed-loop examples;
- sixteen tutorial notebooks and five lecture PDFs;
- GitHub Actions tests on Python 3.10, 3.11, and 3.12; and
- MIT license and updated citation metadata.

The immutable Git tag for this release is `v1.0.0`.
The version-specific software archive is identified by DOI
`10.5281/zenodo.22073935`.
