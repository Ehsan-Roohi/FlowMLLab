# Re=100 cylinder grid-independence evidence

This directory is generated by:

```bash
python qa/run_cylinder_grid_independence.py --regenerate --workers 3
```

The study changes only the spatial lattice resolution.  It keeps `Re=100`,
the lattice Mach number, the `20D x 8D` domain, boundary models, deterministic
perturbation, `100D/U` observation time, and `45D/U` transient removal fixed.
The cylinder resolutions are 12, 18, and 27 nodes per diameter, giving a
constant refinement ratio of 1.5. They pass the declared fine-pair sensitivity
limits but do not form a positive-order asymptotic sequence, so no GCI is
accepted. The failure is retained and `D/dx=40` is the next required
continuation; no gate is relaxed.
Under constant-Mach acoustic scaling, `tau=0.5+3*U*D/Re` is recomputed as the
number of lattice nodes across `D` changes. This dependent value is reported
for every grid and is not tuned against the answer.

Files:

- `grid_metrics.csv`: settings, statistical-convergence checks, and integral
  outputs on every grid;
- `grid_convergence.csv`: generalized observed order, Richardson limit, fine-pair change,
  GCI, declared tolerances, and pass/fail for drag, Strouhal number, and
  recirculation length;
- `grid_protocol.json`: frozen variables, changed variable, equations, gates,
  environment, and scope warning;
- `grid_summary.json`: release-gate result and hashes;
- `re100_D*.npz`: direct LBM fields and complete force/density histories; and
- `cylinder_grid_independence.png/.pdf`: student-facing verification figure.

Grid independence is **solution verification**, not physical validation.  A
pass applies only to the declared outputs at the fixed domain and boundary
conditions.  Domain/blockage sensitivity, Mach-number sensitivity, sampling
convergence, and comparison with independent CFD/DNS remain distinct steps.
The neural evidence already in this release uses the low-cost 12-node dataset
and remains labelled educational; a small ML-to-LBM error cannot remove CFD
discretization or boundary bias.
