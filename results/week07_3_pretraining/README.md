## Frozen protocol

- Field: transverse velocity `v/U` on the 32 x 78 wake window; patches of 4 x 6 pixels (8 x 13 = 104 patches); mask ratio 0.75.
- Unlabelled pretraining trajectories: Re = 90, 100; validation trajectory for every selection (POD rank, ridge strength, early stopping): Re = 105; target: Re = 110, labelled pool frames `[0, 160)`, test window `[210, 281)` with fixed random masks.
- Labelled frames k in [1, 2, 4, 8, 16, 32, 64, 128]; mask seeds [0, 1, 2] (each seed changes the test masks and the drawn frames).
- MAE: 90,168 parameters (dim 64, depth 2, 4 heads, decoder dim 32, decoder depth 1); pretraining 5000 AdamW steps, batch 8, learning rate 0.002, fresh masks every step, weights restored from step 4189 (63 s).
- Downstream: 300 steps, batch 8, learning rate 0.002 from scratch and 0.0005 for fine-tuning; 8 random masks per labelled frame for the probe; ridge strengths [0.001, 0.01, 0.1, 1.0, 10.0, 100.0]; POD ranks [1, 2, 4, 6, 8, 12, 16, 24, 32, 48, 64] (at most k - 1 for the target-only basis).
- Transferred POD basis: rank 64 selected on Re = 105.

## Reading

Fine-tuning the pretrained model beats the same architecture from scratch at every k under the same downstream budget, and by the largest margin at small k; with the full pretraining budget the from-scratch model still fails at k = 2. Gappy POD with the transferred basis is an order of magnitude more accurate than the network with zero labels, and the pooled basis improves with every label: on this periodic, low-rank educational wake the classical method with matched information wins. The target trajectory was inspected in earlier weeks; this is a protocol demonstration, not a blind benchmark.
