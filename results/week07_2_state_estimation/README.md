## Frozen protocol and result

- Training frames: `[0,160)`; validation: `[160,210)`; test: `[210,281)`.
- Field: transverse velocity `v/U`; 32 x 78 fluid-only wake ROI.
- Synthetic point-sensor noise: Gaussian, standard deviation 10% of training-field RMS.
- Five fixed validation seeds select rank, sensor count and process-covariance scale.
- Five different fixed seeds are used for final evaluation.
- Selected on validation: POD rank 8, 32 sensors, process covariance scale 1000.

| Method | Mean test relative L2 | Sample SD across 5 noise seeds |
| --- | ---: | ---: |
| Causal Kalman filter | 2.179% | 0.066% |
| Sensor-only POD reconstruction | 3.163% | 0.064% |
| Open-loop DMD | 4.359% | 0% |
| Persistence | 131.813% | 0% |

The nominal 95% marginal interval has 55.10% mean pointwise coverage and mean
full width 0.00760 in `v/U`. It is severely under-dispersed. These are marginal
POD-space Gaussian intervals, not simultaneous spatial bands. No calibration
factor was chosen using test coverage.

The five seeds perturb measurements of one CFD trajectory; they are not five
independent CFD realizations and do not justify population confidence intervals.
See `metrics.json` for all candidates, per-seed scores, environment and hashes.
