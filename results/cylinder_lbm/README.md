# Week-5 cylinder LBM evidence

This directory retains the executed five-case **quick teaching** sweep generated
by:

```bash
python qa/run_cylinder_lbm_validation.py --regenerate --fidelity quick --workers 5
```

The release gate verifies the committed evidence without rerunning the sweep:

```bash
flowmllab cylinder --root .
```

`regime_metrics.csv` is the primary table.  It records numerical settings,
density drift, force statistics, Strouhal number, recirculation length, and both
qualitative-regime and literature-reference flags.  The quick profile passes
the stability and regime gates; it intentionally does **not** claim quantitative
force or recirculation agreement.  Its coarsely resolved Bouzidi-interpolated
circular wall, 1/6 blockage, finite observation time, and periodic transverse
images explain the failed reference flags.

`reference_ranges.csv` records the educational comparison bands from Gautier,
Biau & Lamballais (2013) and Qu et al. (2013).  To enforce those bands, rerun the
`validation` profile and add independent grid, domain, Mach-number, and
sampling-window studies.  That profile is expensive by design.

The NPZ files contain direct final LBM fields and complete force/density
histories; no field in this evidence directory is generated by ML.  The neural
exercise in the Week-5 notebook uses solver snapshots with a complete Reynolds
holdout and compares against a non-neural POD baseline.
