# Week 10 - Article-backed DSMC surrogates

`W10_DSMC_Data_Driven_Surrogates_Student.ipynb` teaches the full chain from
DSMC data auditing to cavity log-Kn synthesis and monatomic/diatomic shock
operators. It regenerates the retained results with:

```bash
python qa/build_week10_aescte_dsmc_data.py
python qa/run_week10_aescte_validation.py
```

The notebook is generated by `make_week10_notebook.py` and is safe to rebuild
without hand-editing JSON.

## Week 10.1 — Ab initio collision DeepONet

Continue with the [lecture companion](../../lectures/week10_1_abinitio_collision_deeponet.md)
and [colored cylinder contours](../../results/abinitio_deeponet_cylinder/README.md).
This author-supplied research case learns molecular scattering, not the whole
flow field. It is related to [Roohi et al., PoF 38, 057123 (2026)](https://doi.org/10.1063/5.0328463),
but uses the later DeepONet package rather than the article's MLP. The plotted
outputs have different times and sampling windows. This is supplemental
reading; no new executable notebook is added.
