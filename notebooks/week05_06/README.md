# Weeks 5–6: combined guided-project pack

This is the original two-week project module supplied for MIE 690A. It is one
continuous workflow, not two unrelated notebook sets.

- **Week 5:** run `P0_Project_Setup.ipynb`, choose one track, reproduce its
  baseline, freeze the split/configuration, and submit the mandatory checkpoint.
- **Week 6:** continue the same selected track, complete physical and numerical
  validation, document one failure or limitation, and submit the executed
  notebook, reproducibility files, report, and presentation.

The available track notebooks are:

- `P1_Re_Generalization.ipynb`
- `P2_Physics_Guided_DNN.ipynb`
- `P3_POD_Study.ipynb`
- `P4_Uncertainty_Study.ipynb`
- `P5_Rarefied_Cavity.ipynb`
- `P6_FP_Cavity_Closure.ipynb`

The authoritative lecture and project map is
`../../lectures/week05_06_project_guide.pdf`.
