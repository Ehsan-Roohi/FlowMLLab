# Running and interpreting the laboratories

Use Colab, or create a local Python 3.12/3.13 environment from the repository
root. The package supports Python >=3.10,<3.14; the following example chooses
3.12. NumPy must remain below 2.3 for the recorded dependency contract.

```bash
python3.12 -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip install -e ".[test]"
```

For Weeks 7.3 and 11 neural cells, install CPU PyTorch explicitly before running:

```bash
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
```

The optional Week 9 branch/trunk implementation uses TensorFlow/Keras:

```bash
python -m pip install -e ".[ml]"
```

Restart the notebook kernel after changing the environment, then Run All from
the beginning. Do not mix objects fitted under different settings by rerunning
only the last scoring cell. CPU training in Week 7.3 can take tens of minutes;
its long scratch control is part of the intended compute comparison. Optional
full CFD regeneration and model retraining can take substantially longer.

## What each result represents

| Term | Meaning | Appropriate interpretation |
|---|---|---|
| Fresh calculation | Computed by the current run | Report its settings, output path and environment. |
| Retained author evidence | Loaded from versioned tables, weights or images | Inspect or replay the recorded experiment; do not claim a new training run. |
| Training case | Used to fit weights, modes or preprocessing | Measures fit, not generalization. |
| Validation case | Used for selection, stopping or calibration | Freeze all choices before final evaluation. |
| Blind case | Uninspected when the protocol was frozen | Score once; do not tune against its result. |
| Historical holdout / regression case | Excluded from fitting but previously inspected | Useful for checking changes; it is no longer fresh blind evidence. |
| Weak reference | Generated by a specified diagnostic or labeling rule | Agreement with the rule is not independent physical accuracy. |

A notebook can contain both fresh and retained calculations. Follow the path
printed by the code: `results/` holds retained evidence, while fresh runs use
`student_runs/`, a temporary directory, or another explicitly printed location.
Do not compare two percentages until their reference, support, normalization,
split and information budget agree.

## A model name describes its implemented inputs and architecture

A coordinate MLP maps input features to outputs. A branch/trunk DeepONet combines
an encoding of an input function with query-coordinate features. A field
interpolator blends known fields. Reading a paper that used a DeepONet does not
make a classroom MLP or interpolation result a DeepONet result.

For every comparison, report the classical baseline, including cases where it
wins. State source labels, target labels, unlabelled frames, engineered features,
training steps and random seeds. A low error on a weak reference can be useful
without proving physical generalization or superiority over a transparent rule.
