Read the shared prompt
Create a delightful 12-second looping animation of a pelican piloting a pedal-powered flying machine.

Deliver one self-contained HTML file using hand-authored SVG, CSS, and JavaScript. Use no external assets, libraries, image generators, or network requests.

Tell this story:
0–3 seconds: the pelican starts pedaling; a visible chain drives the propeller.
3–6 seconds: the machine rolls forward, accelerates, and takes off.
6–9 seconds: it flies through a small cloud; the pelican looks pleased.
9–12 seconds: it lands and returns smoothly to the opening state.

Make the pelican unmistakable: long bill, throat pouch, wings, and webbed feet. Keep its feet attached to the moving pedals. The crank, chain, propeller, and wheels must move coherently. Keep the machine structurally connected throughout the animation. Avoid sudden jumps, disconnected parts, or objects passing through each other.

Choose your own distinctive illustration style and machine design. Prioritize character, visual clarity, and charm over decorative complexity.

Use a fixed 16:9 camera view. Show the complete scene immediately. Include only Pause/Play and Restart controls.

Return the complete HTML code.
What to look for

Watch the loop boundary, the feet on the pedals, the chain and propeller, the ground contact during landing, and the pilot’s expression. A similar visual style is not evidence of similar mechanical correctness.

The outputs were produced sequentially with shared conversation context and some tool-assisted checks. They were not blind, independent, single-shot API trials. Original HTML files are preserved byte-for-byte for this publication; known imperfections have not been repaired to make the comparison look better.
