# FlowMLLab v1.0.2

FlowMLLab v1.0.2 is the final corrective archival release prepared for the
SoftwareX submission.

## Changes from v1.0.1

- aligns the package version test with the declared software version;
- updates package, citation, README, and Zenodo metadata to version 1.0.2;
- retains the validated solvers, fixed data, notebooks, lectures, and scientific results;
- records the MIT License and version DOI `10.5281/zenodo.22074237`; and
- preserves the standalone repository boundary with no separate JFM or R13/R26 materials.

Before publication, the tag archive is checked with `unzip -t`. It is then
installed in a clean environment. Unit tests, `flowmllab smoke`,
`flowmllab qa`, and the Python 3.10--3.12 GitHub Actions matrix must pass.

Version 1.0.2 supersedes v1.0.0 and v1.0.1 for citation and SoftwareX evaluation.
